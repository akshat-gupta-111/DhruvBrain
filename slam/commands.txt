================================================================================
  JETSON ORIN NANO + MAC SSH: COMPLETE ROS 2 MASTER OPERATION GUIDE
  METHOD B: SYSTEM TRACKING WITH LIDAR-BASED SOFTWARE ODOMETRY (RF2O)
================================================================================

[PREREQUISITES]
1. Your Mac and Jetson Orin Nano must be connected to the exact same local Wi-Fi router.
2. The Jetson must have the NVIDIA Container Toolkit configured.
3. Keep all coordinates strictly hardcoded to '/root/' inside the system.

--------------------------------------------------------------------------------
PHASE 1: MULTI-TERMINAL CONNECTION MANAGEMENT FROM YOUR MAC
--------------------------------------------------------------------------------
Open three or four independent tabs/windows in your Mac Terminal app and connect via SSH:

- Terminal 1 (Main Interactive Program):
  ssh jetson@<YOUR_JETSON_IP>

- Terminal 2 (LiDAR Sensor Node):
  ssh jetson@<YOUR_JETSON_IP>

- Terminal 3 (Laser Odometry Node):
  ssh jetson@<YOUR_JETSON_IP>

- Terminal 4 (SLAM Toolbox Mapper / Nav2 Engine Launcher):
  ssh jetson@<YOUR_JETSON_IP>

--------------------------------------------------------------------------------
PHASE 2: BUILD AND INITIALIZE DETACHED SYSTEM LAYERS
--------------------------------------------------------------------------------
Execute the following setup commands inside Terminal 1:

# 1. Access your target directory layout
mkdir -p ~/robot_project && cd ~/robot_project

# 2. Build the structural image block (Compiles ROS 2 dependencies and rf2o_laser_odometry)
docker build -t jetson_robot_manager .

# 3. Spin up the primary interactive system instance
docker run -it --name=my_robot_app --privileged --net=host -v /dev:/dev -v ~/:/root/ jetson_robot_manager

*Terminal 1 will clear and lock onto the Python selection menu (Options 1-5).*

--------------------------------------------------------------------------------
PHASE 3: RUN THE ACTIVE MAPPING PIPELINE
--------------------------------------------------------------------------------
Follow these steps exactly to discover and record layout points in real-time:

Step 1 [Terminal 1]: Type '1' and press Enter to select 'start_mapping'.

Step 2 [Terminal 2]: Route into the core thread container and boot your LiDAR:
  docker exec -it my_robot_app bash
  ros2 launch rplidar_ros rplidar_node_launch.py

Step 3 [Terminal 3]: Route into the container and boot the Software Odometry tracking node:
  docker exec -it my_robot_app bash
  ros2 run rf2o_laser_odometry rf2o_laser_odometry_node --ros-args \
    -p laser_scan_topic:=/scan \
    -p odom_topic:=/odom \
    -p publish_tf:=true \
    -p base_frame_id:=base_link \
    -p odom_frame_id:=odom

Step 4 [Terminal 4]: Route into the container and boot the SLAM Graph generation solver:
  docker exec -it my_robot_app bash
  ros2 launch slam_toolbox online_async_launch.py

Step 5 [Mac Browser View]: Open your desktop browser and go to:
  http://<YOUR_JETSON_IP>:8000
  *Verify you can see the live black/white grid map updating.*

Step 6 [Terminal 1 - Pinned Checkpoints]: Teleoperate/drive the robot. When it reaches 
  your target desk area, go to Terminal 1, type '2', and input name: desk_area
  (You can repeat this at other locations like kitchen, door, etc.)

Step 7 [Terminal 1 - Save and Export]: Once mapping is complete, choose choice '3' 
  in Terminal 1. Enter the prefix name: apartment
  *This writes apartment_map.yaml, apartment_map.pgm, and apartment_checkpoints.json to your folder.*

--------------------------------------------------------------------------------
PHASE 4: TRANSITION AND AUTONOMOUS TESTING PROTOCOL
--------------------------------------------------------------------------------
To switch from mapping to point-to-point path planning while preserving collision layers:

Step 1 [Terminal 4]: Press 'Ctrl + C' in Terminal 4 to stop the slam_toolbox mapper.
  *DO NOT turn off Terminal 2 (LiDAR) or Terminal 3 (Laser Odometry).*

Step 2 [Terminal 4]: In the now vacant Terminal 4, fire up the Nav2 navigation architecture:
  ros2 launch nav2_bringup bringup_launch.py map:=/root/apartment_map.yaml use_sim_time:=false

Step 3 [Terminal 1]: Return to your interactive menu window in Terminal 1.
  - Type '4' to execute 'test_mapping'.
  - When prompted for the room layout: Type 'apartment'
  - When prompted for the checkpoint destination: Type 'desk_area'

*Nav2 will immediately command the robot to travel to the target while using its live costmap layers to dynamically route around unexpected obstacles!*
