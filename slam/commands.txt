================================================================================
  DHRUV SLAM — SIMPLIFIED DOCKER COMPOSE WORKFLOW
  Hardware: NVIDIA Jetson Orin Nano | RPLidar A1 | ROS 2 Humble
================================================================================

  The old 4-terminal manual setup is fully obsolete. The entrypoint script 
  inside the container now automatically starts all ROS 2 nodes in the exact 
  order needed, and the web UI has replaced the old terminal menu.

  ── FIRST TIME SETUP (or after editing dockerfile) ────────

    cd ~/Desktop/DhruvBrain/slam
    sudo docker compose build

  ── DAILY USE (One Command) ───────────────────────────────

    # Start the full SLAM stack in the background
    cd ~/Desktop/DhruvBrain/slam
    sudo docker compose up -d

    # That's it! Everything is running.

  ── LIVE WEB UI (Control Panel) ───────────────────────────

    Go to:  http://<YOUR_JETSON_IP>:8000

    You will see the live map stream and 4 colored buttons:
      1. Status         - Check if the map is generating
      2. Set Checkpoint - Drop a named pin where the robot is
      3. Save Map       - Save the map and checkpoints to disk
      4. Navigate To    - Pick a checkpoint and drive there!

    You DO NOT need to attach to the terminal anymore. All controls 
    and logs are visible directly in your browser.

  ── STOPPING ──────────────────────────────────────────────

    cd ~/Desktop/DhruvBrain/slam
    sudo docker compose down

  ── TROUBLESHOOTING ───────────────────────────────────────

    If the map doesn't show up in the browser, check the logs:
    sudo docker compose logs -f slam

    (If you get LiDAR error 80008002, physically unplug the LiDAR USB 
    cable, wait 3 seconds, plug it back in, and restart the container).

  ── EDITING PYTHON CODE ───────────────────────────────────

    You DO NOT need to rebuild the Docker image when you change python files.
    The `robot_manager.py` file is hot-mounted from your Jetson host.

    1. git pull (on Jetson host)
    2. sudo docker compose restart
